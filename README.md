# Dead Pixel Check

A minimal, full-screen tool for inspecting displays for dead, stuck, or subpixel-defective pixels.

**Live:** https://egowic.github.io/Dead-Pixel-Check-Claude/

## Controls

| Action | Effect |
|---|---|
| `Space` / `Click` / `Tap` | Next color |
| `←` | Previous color |
| `Esc` / `✕` button | Exit |

## Colors

9-color sequence: Black → White → Red → Green → Blue → Cyan → Magenta → Yellow → Gray

## Dev

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # output → dist/
```
